개인정보처리방침

kacarong.kr · 시행일 2026년 11월 19일

kacarong.kr(이하 "사이트")은 운영자 한 명이 개인 포트폴리오와 작업공간으로 쓰는 사이트입니다. 방문자는 회원가입 없이 공개 포트폴리오만 볼 수 있고, 관리 화면(/admin)은 운영자만 로그인할 수 있습니다.

1. 수집하는 정보

  • 공개 포트폴리오 방문자: 개인정보를 수집하지 않습니다. 쿠키도 쓰지 않습니다.
  • 운영자 구글 로그인: 구글 계정 이메일 주소(본인 확인용)와 구글이 발급한 인증 토큰.
  • 로그인 상태 유지: 관리 화면 로그인 시 세션 쿠키 1개.

2. 구글 사용자 데이터의 사용

사이트는 구글 로그인(openid, email), 구글 드라이브(drive.file), 구글 캘린더 읽기(calendar.readonly) 권한만 요청합니다. drive.file 권한으로는 사이트가 직접 만든 파일과 폴더에만 접근하며, 운영자가 올린 파일을 운영자 본인의 구글 드라이브에 보관하고, 사이트에서 열거나 받을 때 읽어 오는 데만 씁니다. 공개 포트폴리오에 넣은 파일은 사이트가 대신 보여 주며, 드라이브의 공유 설정은 바꾸지 않습니다. 그 밖의 드라이브 파일은 읽지 않습니다.

calendar.readonly 권한으로는 운영자의 캘린더 목록과 일정을 읽어 관리 화면의 캘린더에 보여 주기만 합니다. 일정을 만들거나 고치거나 지우지 않고, 일정 내용을 사이트 서버에 저장하지 않습니다.

사이트가 구글 API로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 구글 사용자 데이터를 광고에 쓰거나 판매하지 않고, 제3자에게 제공하지 않습니다.

3. 보관과 삭제

구글 인증 토큰은 사이트 서버에만 저장하며, 서버에서 직접 지우기 전까지 남아 있습니다. 서버에 남은 토큰과 로그인 기록을 지우려면 아래 문의처로 요청해 주세요. 운영자가 서버에서 삭제합니다.

사이트의 접근 권한은 구글 계정의 서드파티 앱 관리에서 언제든 해제할 수 있습니다. 해제하면 서버에 남은 토큰은 더 이상 쓸 수 없게 되지만, 서버의 토큰 자체가 자동으로 지워지지는 않습니다. 파일은 운영자의 구글 드라이브에 있으므로 드라이브에서 직접 지울 수 있습니다.

4. 문의

개인정보 관련 문의는 구글 로그인 동의 화면에 표시된 사용자 지원 이메일로 보내 주세요.
