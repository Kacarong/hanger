    노션 연동

    1. 컴퓨터 브라우저로 노션 개발자 포털의 토큰 페이지에 들어가 "New token"을 누릅니다. 이름을 넣고 기능은 꼭 "Notion API"를 고른 뒤(Workers만 고르면 연동이 안 됩니다) 기간을 정하고 "Create token"을 누릅니다. 워크스페이스를 물으면 연동할 곳을 고릅니다. 나온 토큰은 다시 볼 수 없으니 바로 복사합니다. 이 토큰은 내 노션 권한 그대로라서 내가 볼 수 있는 페이지가 모두 노트가 됩니다. 무료·Business 요금제는 기본으로 워크스페이스 소유자만 토큰을 만들 수 있습니다(무료는 바꿀 수 없음).
    2. 일부 페이지만 연동하려면 토큰 대신 같은 포털의 Internal connections에서 연결을 만들고(워크스페이스 소유자만 가능) Configuration 탭의 API token을 복사한 뒤, Content access 탭에서 페이지를 고릅니다. 이때는 Capabilities에서 내용 읽기·수정·추가를 모두 켜 두세요.
    3. 토큰을 아래에 붙여 넣고 연결을 누릅니다. 토큰은 서버에 저장해 두고 계속 씁니다(토큰 기간이 끝나면 새 토큰을 다시 넣어 주세요).

    연결하면 노션 페이지마다 노트가 되고, 서식·들여쓰기·토글·표·사진이 그대로 보입니다. 여기서 고치면 몇 초 안에 노션에도 저장되고, 노션에서 고친 것은 1분 안에(열어 둔 노트는 더 빨리) 여기에 들어옵니다. 양쪽에서 같은 블록을 동시에 고치면 이 사이트 쪽이 남습니다. 버튼처럼 노션 API가 내주지 않는 블록은 "노션에서 열기"로 보세요.
